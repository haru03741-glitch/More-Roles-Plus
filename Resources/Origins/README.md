# 役職の「From:」(移植元の mod)

役職の説明の先頭に出る「From: SuperNewRoles」のような 1 行は、このフォルダーのファイルから作ります。

## 足し方

1. このフォルダーに `<鍵>.txt` を作ります (鍵は好きな短い名前。例: `TOH.txt`)。

   ```
   # コメントは「#」から
   name: TownOfHost
   color: #00BFFF
   ```

   - `name:` 出す名前
   - `color:` 名前の色 (省けば白)。色をいくつも並べると **1 文字ずつ** 順に付けます (色が足りない所は最後の色のまま)
     - `name: Super|New|Roles` のように `|` で区切ると、**区切りごと** に順に付けます (`|` は出ません)
     - 例: `color: #FFA500 #FF0000 #00FF00`
   - `gradient:` 色を 2 つ以上並べると、1 文字ずつ滑らかに色を変えます (例: `gradient: #00BFFF #7FE3FF`)。色が 1 つだけなら、その色 1 色で塗ります
   - `name:` も `color:` も書かなければ、ファイルの字をそのまま出します (`<color=#FF0000>TOR</color>` のような飾りも使えます)

2. 絵 (ロゴ) も出したい時は、同じ鍵で `<鍵>.png` を置きます (例: `TOH.png`)。名前の前に字の高さで出ます。絵だけで名前を出さないなら `.txt` は要りません。

3. 役職のコード (`src/Roles/…/<役職>.cs`) に 1 行足します。

   ```csharp
   public override string Origin => "TOH";
   ```

   いくつもの mod から来た役職は `"TOR, SNR"` のようにカンマで並べます。

4. ビルドすると、役職辞典・設定画面の役職の説明・チャットの `/r` に出ます。

鍵のファイルが無い時は、鍵の字をそのまま出します。
